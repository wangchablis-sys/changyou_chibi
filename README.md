# 畅游赤壁

静态提案站：把赤壁市博物馆、三国赤壁古战场、羊楼洞古镇连成一套「全域体验」文旅体系。

核心路径是 **博物馆读赤壁 → 古战场游赤壁 → 羊楼洞品赤壁**。页面用一张「一票、一图、一码、一线」把分散景点重新组织起来，让游客从「逛几个景区」变成「体验一座城市」。

## 本地预览

这是纯静态站点，不依赖构建工具。任选一种方式打开即可：

```bash
# 在项目根目录启动本地服务
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。也可以直接用浏览器打开 `index.html`。

## 页面内容

- **问题**：三个点位各自的短板，以及「景点各自为战」的共同原因
- **三站**：一站知赤壁、一战游三国、一盏品赤壁
- **下一站导览**：在博物馆出口模拟数字屏，按兴趣导向古战场或羊楼洞
- **一码 / 一线 / 四个一**：统一数字入口、文旅专线、组合权益
- **规划行程**：按兴趣生成一日或两日演示线路
