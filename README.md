# 畅游赤壁

静态提案站：把赤壁市博物馆、三国赤壁古战场、羊楼洞古镇连成一座城。

核心路径是 **读懂赤壁 → 走进赤壁 → 带走赤壁**。页面用「一票、一图、一码、一线」把三处重新连起来，让游客从逛几个景区，变成游一座城。

## 本地预览

这是纯静态站点，不依赖构建工具。任选一种方式打开即可：

```bash
# 在项目根目录启动本地服务
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。也可以直接用浏览器打开 `index.html`。

## 页面内容

- **为何**：三处各有本事，游客的一天却是碎的
- **三站**：一站知赤壁、一战游三国、一盏品赤壁
- **看见赤壁**：摩崖、古战场、羊楼洞、陆水湖宣传照片
- **官网入口**：市政府、市文旅局、博物馆公告、咸宁景区简介、省文旅厅
- **下一站导览**：博物馆出口选去古战场还是羊楼洞
- **一码 / 专线 / 四个一**：扫一次码，专线跑通最后一公里
- **规划行程**：按兴趣生成一日或两日线路
